## Featured work

- [University Bubble](https://github.com/RettWilson22/university-bubble-showcase): a campus social app for Auburn students with group chats, DMs, dining, housing and events. I built it solo and shipped it to TestFlight. React Native, Expo, TypeScript, Supabase and Postgres.
- [Back of the Book](https://github.com/RettWilson22/back-of-the-book) ([live demo](https://backofthebook.streamlit.app)): a study app that answers from your course materials with page citations, writes practice quizzes, and makes a quiz on any topic from Wikipedia, with every answer checked against its source. Python, RAG with hybrid search and reranking, Claude or Groq, and Streamlit.
- [Gridiron Lakehouse](https://github.com/RettWilson22/gridiron-lakehouse) ([live demo](https://gridiron-lakehouse.streamlit.app)): a weekly fantasy football cheat sheet with floor-to-ceiling projection ranges for every player, backtested on 2023-2025 against simple averages and expert rankings. The data pipeline is split across Databricks (Lakeflow, MLflow, Unity Catalog) and Snowflake (dbt, Snowpark, streams and tasks), with PySpark and a Streamlit front end.
- [AI Education Chatbot](https://github.com/AI-Education-Chatbot-Team/RAG-model): a team RAG chatbot that answers questions from uploaded course documents. I wrote the deployment docs and change log, and have an open PR ([#29](https://github.com/AI-Education-Chatbot-Team/RAG-model/pull/29)) that adds a CI/CD pipeline and tests. Python, Streamlit, Supabase pgvector, Groq and GitHub Actions.
- [Taste & See](https://tasteandsee34.com): the live website for a local catering and event design business, with an owner edit mode, photo uploads and a contact form. It uses a CSP, HttpOnly sessions and upload validation. HTML, CSS and JavaScript, with Netlify Functions and Edge Functions.

## For fun

[Saturation Guy](https://github.com/RettWilson22/saturation-guy) is a Fabric mod for Minecraft 26.3. It shows your hidden saturation as a bar over the hunger bar (synced from the server every tick when the server has the mod too) and adds a few chat callouts, like announcing your pickaxe is about to break. It has an automated in-game test that boots the client and checks each feature.
